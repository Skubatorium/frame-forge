Gold-gradient call to action; the only button family on the site.

```jsx
<Button href="film.html">Film ansehen</Button>
<Button variant="secondary" href="/videos/jga-2026-4k.mp4" download>4K herunterladen</Button>
<Button variant="ghost" as="button">Abbrechen</Button>
```

- `primary` (gold gradient + glow) — one per view, max.
- `secondary` (pink neon outline) — the alternative next to a primary.
- `ghost` — tertiary, quiet contexts (Impressum, meta).
- Label style is uppercase with wide tracking; keep it to 2–4 words, German.
