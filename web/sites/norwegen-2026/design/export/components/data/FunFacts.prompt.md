Nur auf der Faktenseite, ganz unten. Der einzige Ort, an dem der Ton augenzwinkernd wird.

```jsx
<FunFacts items={[{ value: "1", unit: "Fisch", text: <>Gefangen an der Schärenküste, <b>winzig</b>.</> }]} />
```

Jede Zeile ist eine Pointe: Zahl links, ein Satz rechts. `cool` etwa jede dritte Zeile, sonst wirkt es bunt.
