Aktions-Element in vier Varianten — auf jeder Seite höchstens ein primärer Button pro Abschnitt.

```jsx
<Button variant="primary" href="film-vlog.html" arrow>Roadtrip ansehen</Button>
<Button variant="download" href="/videos/vlog-edit-4k.mp4" download size="6,8 GB">Roadtrip in 4K</Button>
```

- `primary` = Sandgold auf dunkel, `secondary` = 1px-Rahmen, `download` = angehobene Fläche + Größenangabe, `ghost` = Textlink mit Pfeil.
- Nie Schatten, nie Verlauf, nie Großbuchstaben. Mindesthöhe 46 px.
